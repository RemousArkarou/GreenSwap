GreenSwap:

GreenSwap is a site where growers can sell their plants and other people can buy them. The application opperates 
with it's own currencies handed out by the admins. When registering you, you can choose whether you'll be a grower or
buyer.




Conventions:

1.	Maps and files are written in Upper Camel Case.
2.	Variables are named logically, so that you immediately know what they do/what value they hold.
3.	When someone sets a review, they have to mention it in Teams, so that the rest can review it.
4.	We work in branches. A new branch for every sepperate part.
5.	When you're done with a branch, you merge the main into it, fix the merge conflicts and then merge the branch in the main.
6.	Before merging the main into your branch, let your teammates know, so that they don’t make changes to the main while you’re fixing conflicts.
7.	We work in light mode.
8.	We keep github up to date and tell each others when changes in the project were made.
9.	Code needs to look clean, with tabs where they are required to correctly show the parent to child relationships.
10.	We put comments above code, so it’s easy to understand/explain.
11.	We write double code as little as possible.
12.	The name of classes are singular.
13. We only use Curiogpt as AI help.
